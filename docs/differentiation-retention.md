# FlowerStudio：差异化与用户留存讨论稿

状态：产品假设与验证建议，新增功能尚未确认为开发范围。

日期：2026-10-12

关联：[功能模块](functional-modules.md)、[UI 方案](ui-plan.md)、[写实视觉](visual-strategy.md)、[商家与购买](purchase-journey.md)。

## 1. 本轮问题

面对已有插花小程序、数字花束工具及鲜花购买服务，FlowerStudio 如何吸引首次使用，并给用户持续回来的理由？

留存需要用真实行为验证。写实、3D、AI、交易入口或作品收藏中的任意单一功能，都不能保证用户持续使用。

## 3. 建议的核心定位

帮助希望在家插花的普通消费者，用自己已有的花瓶、偏好的风格和实际可采购的花材，完成一份喜欢并能亲手实现的作品。

核心价值由几部分共同形成：

1. 写实预览让用户更容易判断形状、比例与搭配。
2. 个性化条件让方案适合用户的花器、空间与偏好。
3. 花材清单与可靠供货降低采购难度。
4. 实操指导帮助用户完成作品。
5. 保存真实成果与反馈，让下一次设计更方便。

这是差异化假设，需要与同类产品及真实用户比较，尚不能宣称独有或已有竞争壁垒。

## 4. 优先用户建议

优先寻找已经有买花习惯、家里有花瓶、希望自己插花，但会为搭配和小量采购费心的人。

他们有可能在自己的换花周期中重复遇到同一问题。首次设计的新鲜感之外，下一次买花是否继续需要 FlowerStudio，是重要验证点。

礼物、节庆设计和纯数字花束娱乐可以作为其他使用场景，不默认同时承担首版的主要定位。

## 5. 首次使用的吸引点

### A. 写实、流畅的搭配体验

- 花型、比例、自然变体与空间关系可信。
- 增减或替换花材时，能清楚看到搭配变化。
- 可快速得到一个可修改的起点。
- 3D 是否带来额外价值由样片验证；保留免登录试用。

风险假设：用户可能只为新鲜感进入，完成一次漂亮画面后不再回来。需观察是否产生真实用花需求。

### B. 为自己的花瓶与场景搭配

候选输入：花瓶高度、口径、常见外形、风格偏好和用途。

可以先选择常见花瓶并手动填写尺寸，资料由用户自愿保存；是否加入花瓶识别或家居照片需另行评估。

建议入口表达：“给我的花瓶配一束花”。具体文案和功能尚未定稿。

### C. 帮助用户实际完成

候选能力：基于经实际验证的模板，提供花材处理、先后顺序、参考高度与搭配过程。

模板可以附设计预览与真实作品照片。通用可视化设计不能默认自动生成可靠、可实现的插花教程。

## 6. 持续使用的候选机制

| 用户再次遇到的需求 | 候选功能 | 为什么可能促使返回 |
| --- | --- | --- |
| 同一个花瓶想换一套风格 | 保存花器、喜欢的色系、上次作品；换花材生成新方案 | 避免每次重新说明个人条件 |
| 又买了一批花，不知道怎么搭 | 手动记录持有花材，推荐可用搭配 | 从已有资源出发解决当前问题 |
| 上次的作品很好，想再做或调整 | 复制配方、季节替换、重新确认供货 | 复用成功经验，减少再次设计和采购的成本 |
| 希望插得更好 | 实物成果记录、个人备注、模板指导及反馈 | 保留自己的实践经验和进步 |
| 想省心买齐花材 | 保存可靠商家和购买方案，确认可供货与替代项 | 用履约体验建立再次购买的理由 |

用户持有花材需要用户确认可用状态，不默认从上次采购推断今天还有多少花材或是否仍然可用。

用户偏好和历史数据应帮助缩短操作、改进方案；无需通过强制填写资料或限制作品带出来制造留存。

分享作品可以帮助传播，但访问者是否转成设计或采购用户需要单独测量。社区、排行榜和积分不是当前留存方案的前置条件。

## 7. 建议的重复价值流程

保存我的花器与偏好
→ 本次选择花材并得到合适方案
→ 采购并实际完成
→ 自愿记录成果与体验
→ 下次沿用花器和成功经验，换一套花材
→ 再次确认供货与采购。

更新模板与当季资料可以提供新的起点；重复价值仍需落在用户自己的需求上。

## 8. 如何验证，避免把热闹当留存

### 需要验证的假设

| 假设 | 可观察行为 |
| --- | --- |
| 写实体验使用户更愿意完成设计 | 模板进入、首次编辑、完成设计、保存或清单生成 |
| 个人花器与偏好有实际价值 | 用户是否自愿保存条件，以及下次是否沿用 |
| 清单能减少采购困难 | 采购需求提交、可履约方案确认、真实采购及失败原因 |
| 指导能帮助用户插成功 | 用户自愿反馈是否完成、满意之处和困难 |
| 形成持续需求 | 30 / 60 天重复完成设计、重复实际采购和重复使用个人场景 |

初期可找一小批有日常买花习惯的人，观察至少两次真实用花过程，结合操作观察和访谈做定性判断。样本积累后再做有明确成功指标的对照实验。

### 指标口径

- 设计完成需有明确行为，不能将随意拖动一次花材算作完成。
- 复购按真实购买记录或合作方核实统计；用户自行反馈单独标记。
- 缺少外部订单回传时，跳转商家和实际购买分别记录。
- 重复使用按用户实际买花或换花周期解释，不默认要求每日使用。
- 记录只为体验新鲜感进入的人与有实际采购需求的人，避免混在一起解释留存。
- 暂不承诺留存率目标或市场表现，先建立实际基线。

## 9. 对功能模块的影响

新增候选需求先映射到现有边界，不为每个卖点立即新建服务：

- M01 花材库：标准花材、计量与基础资料。
- M02 模板：经实物验证的配方、参考作品与指导内容。
- M03 编辑：结合场景条件的搭配与布局。
- M06 作品管理：个人场景、作品、真实成果及个人备注；细化时区分各自数据归属。
- M09 视觉资产与场景呈现：可靠的花材与花器比例、素材和渲染。
- M10—M13 采购：供货、采购方案及交易能力。
- M08 反馈与分析：验证首次价值、实际完成和重复使用。

如果加入“家中已有花材”，应建立用户持有花材记录，引用平台花材标识。个人持有数量不属于平台公共花材库，也不属于商家库存。

模板指导与任意设计生成步骤是不同能力，后者是否开发需要先确认数据和专业校验方式。

## 10. 推荐的投入顺序

1. 继续已确认的写实样片与设计清单目标。
2. 在一小批真实用户中，优先比较“个人花器适配”和“可实现的模板指导”是否增加首次价值。
3. 商家试点验证按配方买齐的可行性与体验。
4. 复用花器、配方和实物成果，观察第二次设计和采购。
5. 根据反馈决定是否扩大推荐、持有花材管理、养护内容、分享或订阅。

上述候选能力还未纳入首版承诺。写实样片、双模式编辑、设计清单及已确认的保存能力继续作为范围基线。

## 11. 当前结论

FlowerStudio 的潜在差异应由写实体验、个人场景、可实现配方及可靠采购共同构成。

首次吸引和长期留存分别验证。以用户第二次遇到用花需求时是否主动回来作为关键观察，而非仅以第一次赞美画面或页面访问量作判断。
