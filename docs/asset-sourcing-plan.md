# FlowerStudio：样片素材获取与 Blender 工作方案

日期：2026-10-12

状态：S0 素材工作建议。已完成第一批 12 组花材下载与 Blender 导入检查，制作 8 款原创花瓶，并整理部分花材样本。详见[第一批素材库](../artifacts/asset-library/README.md)。花材仍为候选，尚未完成正式编辑器中的视觉与支数映射验收。本阶段按用户要求优先获取素材和验证效果，许可分析暂不作为本轮筛选工作。

## 1. 本阶段采用的工作方向

先筛选现成的真实图片和单支花材模型，用 Blender 加工合格模型；只有缺少合格资产时再补充自建或定制。

最小样本从一支玫瑰和一个不透明花瓶开始，通过后扩展到康乃馨和尤加利。花瓶可以按明确尺寸自建，复杂花材优先寻找已有资产。

保持实施计划的固定视角写实与可旋转 3D 对比。若模型合格，从同一源模型输出透明图片与 GLB，有助于控制对比中的花型和素材质量差异。真实照片用于检验外观；照片切图路线若继续考虑，需另外验证真实照片样本。

## 2. 图片与模型分别用于什么

| 素材 | 用途 | 样片筛选条件 |
| --- | --- | --- |
| 实物照片 | 花型、颜色、质感参考；图鉴或模板内容 | 来源明确，花种可辨，使用许可符合实际用途 |
| 单支透明图片 | 固定视角编辑 | 完整花头、花茎和叶片，边缘干净，光照和拍摄角度可统一 |
| 单支 3D 模型 | 空间观察、姿态与遮挡验证 | 有完整花茎和背面，贴图齐全，可独立处理，尺寸和方向可校准 |
| 花瓶 | 场景比例与插入位置验证 | 有高度、口径及单位，优先使用简单不透明花瓶 |

整束花的照片或整组插花模型可以作为参考，但不能直接视为可逐支编辑资产。页面宣称的质量与面数不等于实际导入后的验收结果。

## 3. 已核实的候选来源

### Pexels 图片

- [图片许可](https://www.pexels.com/license/)允许修改及商业用途，并有特定使用限制。
- 可寻找花材照片和真实插花参考；能否得到光照一致的单支切图需逐张筛选。
- 不直接从搜索引擎、小红书、商家页面或其他产品中复制图片作为发布素材。外部作者或商家供图需记录对应授权。

### Sketchfab 可下载模型

- [官方 Creative Commons 介绍](https://www.sketchfab.com/blogs/community/an-introduction-to-creative-commons-licenses/)说明作者可采用不同 CC 许可。
- 优先筛选 CC0 和 CC BY，按具体许可保存署名、来源及许可证信息。
- 免费可下载不代表适合所有商业、修改或发布方式；逐项记录实际许可证。

### Blendkit / BlenderKit

- 候选：[Red Rose Flower，Soran Mohammadi](https://www.blendkit.com/asset-gallery-detail/f357a769-16a9-4ece-a9fe-17d322d6e8ee/)。页面标注免费、1,053 多边形、4K PBR 材质、9.4 MiB、Royalty Free。已下载、导入并渲染；花型偏硬，保留为交互测试候选，网页表现仍待验证。
- [许可说明](https://www.blendkit.com/docs/licenses/)区分 Royalty Free 和 CC0。
- [许可 FAQ](https://www.blendkit.com/docs/licenses/licensing-faq/)允许出售渲染作品，但对游戏中的资产可提取性有约束。
- 因浏览器 3D 需要向客户端传递模型，不能仅凭“可商用”就认定可直接公开 GLB。Royalty Free 候选先评估本机处理和渲染用途；正式网页模型需核实该用途，或选择适合分发的 CC0 / CC BY、自有或另获授权资产。

## 4. Blender 的职责与已验证能力

本机执行路径：`D:\softwares\Blender\blender.exe`。

已通过后台执行验证：Blender 5.2.2 LTS 可运行 Python 脚本并访问场景数据，已用于导入、建模、渲染与 GLB 导出。桌面控制工具已识别安装的 Blender 应用；本轮采用后台脚本工作。

可用于后续工作：

1. 导入已有模型，检查对象、材质与贴图。
2. 校准尺寸、轴向及插入点，按需要拆分单支花材。
3. 创建简单花瓶和试验灯光、相机。
4. 调整材质，制作有限的自然变体，控制模型和纹理体积。
5. 输出透明 PNG、多角度预览、网页 GLB 以及可编辑的 `.blend` 源文件。

脚本可以使处理和输出重复执行；写实质量仍需根据真实照片与实际渲染结果逐轮验收。简单程序花不能替代合格的写实样片。

## 5. 素材记录与验收

每个候选记录作者、原始地址、取得日期、许可及署名要求、允许用途、原始文件、资产版本、花材品种与颜色、实际尺寸及单位。尺寸未知时标记未知，不能把估计值当作实际规格。

样片验收检查：

- 单支是否完整，花型与背面是否可信。
- 数量映射是否明确：一个逻辑实例对应一支实际花材。
- 花头、花茎和花瓶的比例是否合理。
- 组合多支后是否出现明显重复、错误遮挡或不一致光照。
- Blender 输出与网页呈现是否一致，记录加载体积和目标设备表现。
- 许可是否覆盖最终采用的发布方式。

## 6. 下一项具体工作

从已获取的素材中继续筛选、拆分和校准单支花材，优先用粉玫瑰、白郁金香和尤加利制作少量组合，并在网页中验证渲染效果。正式质量验收和渲染路线选择继续以对照样片为依据。
