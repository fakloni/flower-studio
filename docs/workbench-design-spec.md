# FlowerStudio 工作台视觉与交互基线

日期：2026-10-12。状态：S0 设计稿，待实际网页样片校准。

关联：[设计交付入口](../artifacts/workbench-design/README.md)、[原 UI 规划](ui-plan.md)、[工程计划](implementation-plan.md)。

## 1. 本轮范围

第一张业务页面为插花工作台。以花瓶插花展示，保留手持花束入口；首轮网页样片先验证花瓶场景，手持场景的正式布局仍按工程阶段推进。

交付桌面默认状态、手机默认状态、手机选花面板、控件和状态约定，以及可供 2D / 3D 对比的精简素材包。本轮界面为设计概念；以下动作是实现约定，尚未实现。

## 2. 视觉系统

选择自然、温柔的花艺工作室方向。品牌和操作使用植物绿，花材自身提供粉白色彩。维持真实花材与花瓶作为焦点，采用细分隔线和适量留白。

设计稿颜色为生成图中的近似采样；代码实现时以本表作为初始变量，并在浏览器中校准。这里不将生成图中的细微纹理和渐变作为每个控件必须重建的效果。

| 变量 | 初始值 | 用途 |
| --- | --- | --- |
| canvas | #F3F2EC | 工作区背景，暖灰奶白 |
| surface | #FBFAF7 | 面板与花材缩略图背景 |
| text | #263B30 | 标题、正文与数量 |
| muted | #778078 | 保存提示与辅助说明 |
| accent | #335C45 | 主按钮、选中与焦点 |
| subtle | #E2E6DC | 轻选中底色 |
| border | #DEDCD4 | 分隔线、输入框 |

字体：FlowerStudio 品牌用克制的衬线字；中文和操作控件使用易读的无衬线字体，优先系统中文字体。正文 14—16 px，面板标题 20—22 px，作品名称 18—20 px，辅助信息不小于 12 px。图中的字体表现为视觉方向，字体具体文件在工程初始化时选定。

间距使用 4 / 8 / 12 / 16 / 24 / 32 px；常规控件圆角 8 px，面板 12 px；分隔线 1 px。桌面操作控件至少 36 px 高，手机触摸目标至少 44 × 44 px。图标采用同一套细线图标，尺寸 18—20 px，以文字明确重要操作含义。

花材和花瓶图不添加颜色蒙层；缩略图保持原比例，透明边缘与背景自然融合。列表缩略图与画布中的可编辑实例是两个职责，缩略图不用于计算支数。

## 3. 桌面布局

参考图：[desktop.png](../artifacts/workbench-design/desktop.png)，1536 × 1024。

页面由品牌导航、作品条和三栏工作区组成。左栏花材选择，中央画布，右栏配方及花瓶。

| 区域 | 参考组织 | 主要内容 |
| --- | --- | --- |
| 顶部导航 | 约 64 px 高 | FlowerStudio、发现灵感、设计工作台、花材图鉴、我的作品、登录 |
| 作品条 | 外边距约 24 px，约 60 px 高 | 作品名称、保存状态、保存草稿、生成清单 |
| 左侧花材栏 | 参考图约 352 px 宽 | 搜索、全部 / 主花 / 配花 / 叶材、两列缩略图、添加按钮 |
| 中央画布 | 弹性填满，参考图约 760 px 宽 | 场景、编辑方式、重新排布、撤销重做、组合预览、观察视角与缩放 |
| 右侧栏 | 参考图约 354 px 宽 | 配方支数、总支数、选定花瓶及尺寸、更换花瓶 |

桌面两侧栏可在 256—352 px 范围缩减，中央画布优先保留空间。窄屏到不足以同时显示三栏时进入面板布局，不把三栏挤到不可阅读。断点建议 1024 px，实施时通过设备验证调整。

各栏可有自己的滚动区域；作品条和画布主要控件保持可见。正常视口不要求用户滚动整页才能看到保存与清单动作。

## 4. 手机布局

参考图：[mobile.png](../artifacts/workbench-design/mobile.png) 与 [mobile-flowers.png](../artifacts/workbench-design/mobile-flowers.png)，原图约 854 × 1844，可对应约 390 × 844 的逻辑视口。

手机依次为品牌行、作品名称及保存状态、场景与编辑方式、主要画布、观察视角，以及底部面板和固定动作。

- 默认底部面板收起，显示“花材 / 配方 / 花瓶”、当前摘要与展开动作。画布拥有最多空间。
- 点“花材”或展开后显示底部面板，包含搜索、分类和花材选择；面板内容单独滚动。
- 点“配方”显示各花材数量和增减控件；点“花瓶”显示花瓶选择及尺寸。
- 点收起按钮或拖动面板把手收起。面板展开不改配方、不改当前选中对象。
- 保存草稿与生成清单在底部动作区保持可见，处理屏幕安全区。手机键盘弹出时保证搜索框和关闭面板入口可达。
- 在画布上操作对象时，手势不触发页面滚动。面板中的正常滚动不会移动花材。
- 选中花材时展示对象操作，不把全部编辑工具常驻在小屏幕上。

侧面和俯视依所选渲染器开放：3D 可改变观察相机，图片样片只开放已生成的离散角度。2D 正式对象旋转与观察整个场景的视角操作分别表达。

## 5. 配方与对象规则

示例配方：粉玫瑰 3 支、白郁金香 2 支、尤加利 3 支，总计 8 支。此示例用于数量和布局演示，尚未成为经实物验证的发布模板。

| 操作 | 设计变化 | 配方与清单 |
| --- | --- | --- |
| 添加一支 | 新建一个稳定标识的花材实例 | 对应数量 +1 |
| 减少一支 | 删除一支对应实例 | 对应数量 -1；降到 0 后移除该行 |
| 替换花材 | 修改一个选定实例的花材引用，保留可兼容的摆放信息 | 原花材 -1，新花材 +1 |
| 拖动、转动对象 | 更新摆放信息 | 支数不变 |
| 切换自动 / 手动 | 修改操作方式 | 配方、布局和作品均保留 |
| 重新排布 | 按当前实例生成新布局 | 支数不变，能够撤销 |
| 切换观察角度 | 修改相机或可用图片角度 | 不改变对象摆放和数量 |
| 更换花瓶 | 更换花器，检查当前摆放 | 不自动改配方，不静默重排；提供明确的重新排布动作 |

首次拖动一个对象时切换为手动摆放并给出选中反馈。重新排布会替换现有手动布局，初期用简短确认说明及可撤销操作；不默认增加对象锁定功能。

样片仅实现验证所需操作；正式撤销重做、保存与清单范围继续按 S1 / S2 分批完成。

## 6. 必须覆盖的状态

| 状态 | 用户看到什么 | 可继续做什么 |
| --- | --- | --- |
| 空白 | 花瓶或空画布，提示添加花材或选模板 | 选花，生成清单暂不可用 |
| 花材加载 | 对象位置的轻量加载提示 | 编辑已加载对象，避免重复点击创建重复实例 |
| 素材加载失败 | 对应花材名称与重试入口 | 保留实例和支数，重试或删除 |
| 对象选中 | 清楚轮廓与对应操作；配方对应行反馈 | 移动、旋转、删除或取消选中 |
| 数量为 0 | 行移除，画布相应对象消失 | 撤销或重新添加 |
| 手动编辑 | 手动摆放高亮 | 继续编辑或重新排布 |
| 未保存 | “有未保存修改” | 手动保存 |
| 保存中 | “正在保存…” | 继续编辑，合并后续保存 |
| 本机已保存 | “已保存到本机” | 继续编辑，访客无需登录 |
| 保存失败 | “保存失败，修改仍保留”与重试 | 重试，不清空当前设计 |
| 清单预览 | 名称、颜色和支数；返回修改、复制、导出 | 保存生成时的快照 |
| 手机面板展开 | 当前页签和清楚的收起入口 | 面板独立滚动，固定底部动作 |

登录仅表达跨设备保存入口，不使访客无法使用工作台。采购清单第一版不展示未经确认的价格或购买按钮。

## 7. 实现结构建议

按既有工程计划组织页面与模块，不为这轮设计稿新增全量应用骨架。未来工作台可拆为：品牌导航、作品条、花材选择、设计画布、配方栏、花瓶选择、对象工具、手机展开面板，以及清单结果。

业务数量、编辑命令与清单计算保持独立，UI 只呈现状态并发出操作。渲染器从同一份实例数据读取，不让图片节点数或网格数成为采购支数。

## 8. 下一步网页样片验收

1. 以本轮结构承载固定视角图片和 3D 两个样片，使用同一组配方、花瓶与构图目标。
2. 验证增加、减少、选中、移动、重新排布与数量同步。
3. 对比花头、花茎与花瓶比例，验证透明边缘、遮挡和模型背面。
4. 记录首次加载、资源大小、拖动与视角变化表现，并在指定手机设备或明确的模拟条件下测量。
5. 完成浏览器检查后再确定正式渲染路线和最终编辑坐标格式。

设计图中的花束质量不能替代实际模型组合效果；生成概念图与真实网页结果分别记录。
