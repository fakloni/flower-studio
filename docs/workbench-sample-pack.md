## 1. 本轮结果

从已有素材中整理三种单支花材候选，并生成两个花瓶的精简模型。每个花材包按“一支实际花材对应一个逻辑实例”组织，内部仍可以有多个网格和材质。

| 标识 | 内容 | GLB 大小 | 数量含义 |
| --- | --- | --- | --- |
| pink-rose | 单支粉玫瑰，保留花头与花茎 | 约 1.25 MiB | 一个实例一支 |
| white-tulip | 一支白郁金香，补入并调整一片来源叶片 | 约 0.65 MiB | 一个实例一支 |
| eucalyptus | 从原组合提取一个主枝与对应枝叶 | 约 4.61 MiB | 一个实例一枝候选 |
| ivory-bud | 奶油白细口瓶，有内腔 | 约 0.38 MiB | 场景花器 |
| sage-fluted | 鼠尾草绿竖纹瓶，有内腔 | 约 0.38 MiB | 场景花器 |

五个 GLB 合计 7,625,504 字节，约 7.6 MB / 7.27 MiB。大小以清单和文件为准；此数值仅为模型总量，不包含预览图片或 Blender 源文件。网页按选用的花材和花瓶加载，不需要首次加载整个原始素材库。

每项包含正面和侧面两个透明 PNG、对应 WebP、GLB，以及保留相机与灯光的 `.blend` 源文件。图片角度为样片观察约定，不表示花材已经有完整的任意角度图片。

## 2. 做过的处理

- 粉玫瑰：从双支组合中单独提取一个花茎与花头对象，排除原花瓶、水及无关叶材；降低细分等级，缩小贴图。
- 白郁金香：提取一个花茎与花头，选取来源叶片并调整连接位置。未把原花盆或其他花茎一起纳入。
- 尤加利：原文件按材质组合网格。先找到三个主枝连通分量，再以最近连接顶点归属副枝，将叶片归属到主枝与副枝，提取一个主枝的候选。
- 花瓶：在原造型基础上减少几何数量，保留轮廓、瓶口与内腔。
- 贴图：实际解码后将大图最长边缩到 1024 px；GLB 内浮点 PNG 输出转为普通 8 位 PNG，以减少文件体积。透明贴图保留 alpha。

未修改或覆盖原下载模型与上一轮原花瓶，精简包采用独立路径。

## 3. 尺寸与坐标约定

| 内容 | 约定 |
| --- | --- |
| 模型长度单位 | 米 |
| Blender 源模型 | Z 轴向上 |
| GLB 运行时 | glTF 标准 Y 轴向上，由 Blender 导出器转换 |
| 花材源插入点 | [0, 0, 0]，花茎底部附近的锚点 |
| GLB 插入点 | [0, 0, 0] |
| 花茎主要生长方向 | 源模型约 +Z，网页约 +Y；保留自然弯曲 |
| 花瓶口中心 | 根据模型高度记录源坐标与网页坐标 |

花材展示高度分别为粉玫瑰 48 cm、白郁金香 46 cm、尤加利 50 cm，是统一比较所需的工作尺寸，尚未核实实物规格。不能把这些数值直接当成用户实际购买的花茎规格或插花指导。

细口瓶模型高度约 23.2 cm、内口径约 4.2 cm；竖纹瓶模型高度约 26.2 cm、内口径约 9.8 cm。来源是本轮构造模型，不代表市场上已有对应商品。

具体设计文档的二维 / 三维摆放结构仍在对照样片后确定。本轮清单中的运行时坐标用于加载约定，不是已经定稿的作品保存格式。
