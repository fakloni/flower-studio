# FlowerStudio

面向家庭 DIY 插花的写实设计与采购辅助产品。

产品方向：从个人花器和灵感出发，编辑花材与支数，生成清单，并逐步连接实际可供货商家与购买流程。

当前状态：已按照认可的工作台概念稿建立可交互的 Web 原型。六种花材与两款花瓶可直接用于网页 3D 预览，并可切换到图片预览作对照。白郁金香已在 Blender 中构造闭合花瓣的工作台版本，编辑来源见[新增模型](asset-sources/workbench/README.md)。

花材图鉴已接入参考 Excel 的 104 条产品或候选，支持名称／别名搜索、大类与角色筛选，以及季节、尺寸和来源详情。资料与素材使用稳定 ID 关联，保留重复导入、人工补充和历史版本能力。图鉴资料与可编辑素材分别标明状态，现有 6 个编辑示例继续使用。[本地花材库维护指南](docs/local-catalog-guide.md)说明文件位置、更新方法和后续云端迁移。

## 运行与体验

从 GitHub 克隆时，先安装 Git LFS，再运行 `git lfs install` 与 `git lfs pull`，下载 Blender 源文件和网页模型。仓库包含代码、模型源文件、图片、图鉴资料及设计文档；本机依赖、构建缓存、环境密钥和 Blender 自动备份不提交。

需要 Node.js 22.13 或更高版本。首次运行 `npm install`，然后运行 `npm run dev`，打开 <http://127.0.0.1:3000/>。

当前已实现：模板或从零搭配、花材搜索与分类、按支添加和移除、自动排布、拖动和旋转单支花材、替换、撤销与重做、换瓶、三种 3D 视角与缩放。手机端采用可点击或拖动展开的底部面板。

作品自动保存在当前浏览器的 IndexedDB 中，也可手动保存、继续编辑、复制、导出和导入 JSON 文件。生成清单后保留当时的支数，支持复制和下载文本。

校验入口：`npm test`（业务、图鉴、素材与瓶口连接测试）、`npm run test:catalog`（导入和版本更新测试）、`npm run typecheck`、`npm run build`。生产预览先构建，再运行 `npm start`。

独立插花实验页：<http://127.0.0.1:3000/experiments/insertion>。当前使用白玫瑰、白郁金香和银叶桉，验证瓶内支撑、整枝滑动、有限柔弯、邻茎避让、轻微花瓣接触和玻璃透射；支持撤销、重做及浏览器草稿。拖动采用共享碰撞检查和分帧处理。浏览器内保存的作品或草稿属于本机数据，不会随源码上传，需在页面中单独导出。

资料更新入口：`npm run catalog:preview` 预览校验结果，`npm run catalog:import` 发布本地新版本。原始 Excel 保持不变，人工补充在 `data/catalog/overrides.json` 维护，素材关联在 `data/catalog/assets.json` 维护。

目前为本机原型：账号登录、跨设备云端保存、商家供货与交易尚未接入。花材尺寸尚未经实物核验，自动排布是示例规则；花茎在渲染中做瓶口聚拢与遮挡处理，不能替代实物插花或碰撞模拟。部分候选花材仍需改善花瓣、枝叶连接和细节，真实手机的性能也待验证。

素材查看入口：[第一批素材库](artifacts/asset-library/README.md)，包含来源预览、本机实际渲染、模型文件与候选状态。

工作台设计入口：[桌面 / 手机设计稿与样片素材包](artifacts/workbench-design/README.md)，包含视觉与交互基线、三种单支花材候选和两款精简花瓶。

## 开发入口

先阅读 [工程结构与实施路线](docs/implementation-plan.md)。推荐顺序：

1. S0：已有 UI 基线、工程基础和可交互的 2D / 3D 样片；继续精修素材并完成真实设备的渲染路线评估。
2. S1：工作台已跑通模板、双模式编辑、清单与本机保存；继续依据体验反馈完善搭配规则。
3. S2：完善手机体验、作品管理、账号云端保存与内容运营，完成第一版。
4. 后续：第二批图片识别；采购试点和交易方式依据合作结果推进。
