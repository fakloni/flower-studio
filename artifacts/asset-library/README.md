## 当前筛选判断

- 粉玫瑰的花瓣表现较好，可优先用于组合效果验证。白郁金香和尤加利可继续优化姿态与材质。
- 大丽花、浅黄绣球和落新妇候选保留完整高细节原模型，适合继续筛选和拆分。绣球模型包含额外对象，不能按整包包围盒直接缩放。
- 红玫瑰花型偏硬；向日葵几何较轻，叶片和侧面表现有限。先作为交互与性能候选，不作为最终写实质量标准。
- 黄色花材的具体品种尚未确认；观赏花穗与蕨叶也需核实品种。
- 满天星候选主要是装饰球，不适合逐支插花，本轮未纳入下载集合。康乃馨、芍药与洋牡丹尚未取得满意的可下载候选。

花材样本为方便比较统一到 50 cm 的展示高度。此数值是预览规范，不是经确认的花茎真实规格；正式插花比例和采购数量映射仍需校准。
