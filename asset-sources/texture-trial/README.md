# 粉玫瑰贴图对照试验

日期：2026-10-13。页面：`http://127.0.0.1:3000/experiments/flower-textures`。

## 制作方式

- 颜色与轮廓参考：现有 `public/assets/sample-pack/pink-rose-front.png`，500×680。
- Laigter 1.14.0：以原图生成法线、遮蔽和高光贴图，使用默认参数。本轮网页只使用法线，避免把未调校的高光直接叠上去。
- Blender 5.2.2 LTS：从 `asset-sources/sample-pack/pink-rose.blend` 使用相同正交相机，输出材质颜色、相机空间法线、局部遮蔽。法线和遮蔽使用 Raw 数据输出；颜色使用 Standard 输出。
- Krita 5.3.4.1：导入 `rose-matting-test.ora` 两个图层，合成导出带底色 PNG。与程序合成图的平均像素差为 0；本轮没有进行手工修边或绘画。
- rembg 2.0.85：使用 CPU 上的 `u2net` 模型，将 Krita 导出的带底色样本恢复为透明 PNG。

源文件未替换；试验贴图位于 `public/assets/texture-trial`，模型权重位于 Git 忽略的 `.model-cache`。

## 对照范围

原图组不重新受光。Laigter 组保留原图颜色、叠加估计的表面方向。Blender 组使用重新输出的材质颜色、几何表面方向和遮蔽。三组采用相同视角、原图透明轮廓与相同的光照控制，切换花头与完整花枝时同时改变裁切范围。

材质颜色导出不包含本次场景光照，但不能保证来源纹理没有预先烘焙的明暗。网页将朝离固定相机的表面方向翻转后进行双面受光计算，防止薄花瓣可见背面异常发灰。当前光照是简化的漫反射对照，不包含花瓣透光、真实薄片厚度、移动花枝后的接触阴影或形变后的法线更新。

## 处理检查

以原透明图作为这个受控背景试验的轮廓参考，在 alpha > 128 阈值下：

- rembg 输出与原图的轮廓交并比：0.9718。
- 原图前景像素保留率：99.06%。
- 花茎区域（图像第 300 行以下）的前景像素保留率：99.84%。
- Blender 法线渲染与原图轮廓交并比：0.9657。两者包围框左边和上边一致，法线图右侧多约 2 像素；差异包含原材质 alpha、抗锯齿与去噪。因此网页统一使用原图 alpha。

这些数字只描述同一素材添加统一背景后的结果，不代表真实拍摄、复杂背景或其他花材的抠图准确率。

## 当前结论

新增贴图能让固定视角花材响应侧光，Laigter 组带来较轻的表面起伏，模型导出的法线能区分更明确的花瓣方向。

处理没有创造新花瓣细节，也没有修复源模型与源纹理。Blender 组仍能看到材质明暗不均和颗粒状细节；强侧光可能让亮面过亮，背光处偏灰。当前不认定它在所有光照下都比原图好看。

素材库可分别采用：照片素材保留柔和原光影并轻度增加法线；质量合格的模型统一输出材质贴图包。先做花型、颜色和边缘质量验收，再增加光照和动作。

## 可重复执行

`tools/build_texture_trial.py` 用 Blender 生成材质贴图，`tools/prepare_texture_trial.py` 制作分层抠图输入并检查轮廓对齐。Laigter 使用 `--no-gui --diffuse` 与 `--normal --occlusion --specular` 输出。rembg 使用项目的 `tools/remove-background.py`，模型选择 `u2net`。

Laigter 高光和遮蔽输出已保留，但没有在本轮网页中作为真实物理参数使用。OpenRaster 文件可在 Krita 继续编辑。
